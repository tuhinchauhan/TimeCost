# TimeCost PWA

Upload the contents of this folder to the root of the GitHub Pages repository.

Files:
- index.html
- manifest.webmanifest
- sw.js
- icons/icon-192.png
- icons/icon-512.png

After GitHub Pages publishes it over HTTPS, open the site on Android Chrome and use:
Menu (⋮) -> Add to Home screen / Install app.

The expense data in the app is stored locally in the browser using localStorage.
